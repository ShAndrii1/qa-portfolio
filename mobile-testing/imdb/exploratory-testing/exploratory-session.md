# Exploratory Testing Session – IMDb iOS App

## Testing Goal

Explore search functionality and movie details page behavior.

---

## Areas Tested

- Movie search
- Search results page
- Movie details page
- Navigation

---

## Observations

- Search results load quickly.
- Movie details page displays title, rating, and description correctly.
- Navigation between screens works smoothly.

---

## Potential Risks

- Large search queries may impact performance.
- UI layout could break on smaller screens.

---

## Notes

Exploratory testing session focused on identifying usability issues and unexpected behavior during normal user interaction.
