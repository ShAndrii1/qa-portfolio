# IMDb iOS App – Exploratory Testing

## Project Description

This project demonstrates exploratory testing of the IMDb iOS application.

The goal was to explore core application functionality and identify potential usability or functional issues.

---

## Testing Approach

Exploratory testing was performed focusing on key areas of the application:

- Search functionality
- Movie details page
- Navigation between screens
- UI elements and layout

---

## Tools

- iPhone 11 pro, iOS 26.2.1
- Screen recording
