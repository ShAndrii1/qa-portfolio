# EMA-3 – User can't return to the previous stage during setting up a profile

## Preconditions

User should have a newly created profile

## Steps to reproduce

1. Open the “Evernote“ app
2. Tap on the “Complete your setup“
3. Select a couple of settings
4. Try to return to the previous one

## Expected result

User can return to the previous stage

## Actual result

User can’t return to the previous stage

## Priority

High
