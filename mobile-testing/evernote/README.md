# Evernote – Mobile Testing

## Project Description

Evernote is a note-taking and productivity application.

Exploratory and manual testing were performed on a real Android device focusing on user flows.

---

## Testing Scope

Testing focused on core user interactions:

- Account login
- Note creation
- Editing notes
- Navigation between notes

---

## Testing Approach

Testing was performed on a real Android device using exploratory techniques.

The main goal was to validate user flows and identify usability issues.

## Tools

- Android device
- Manual testing
