# Exploratory Testing Session – Evernote

## Testing Goal

Validate the main user flows of the Evernote mobile application.

---

## Areas Tested

- Login flow
- Note creation
- Note editing
- Navigation between notes
- Basic usability of core screens

---

## Testing Approach

Exploratory testing was performed on a real Android device.

The session focused on observing application behavior during normal user interaction and identifying issues in critical user flows.

---

## Observations

- Login flow works as expected.
- Note creation is available and easy to access.
- Editing notes behaves correctly in normal scenarios.
- Navigation between notes is smooth and understandable.

---

## Potential Risks

- Performance may decrease when working with large notes.
- Complex note content may affect usability on smaller screens.
