# Handyman – Android Application Testing

## Project Description

Handyman is a service platform connecting users with professionals for various services.

Manual testing was performed using an Android emulator.

---

## Testing Environment

Testing was executed using:

- Android Studio
- Emulator: Pixel 8
- Android version: Android 16

---

## Testing Approach

Manual exploratory testing was used to evaluate application behavior and identify functional issues.

---

## Tools

- Android Studio
- Android Emulator
- Logcat

Logcat logs were collected to analyze defects.
