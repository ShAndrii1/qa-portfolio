# Exploratory Testing Session – Eventbrite

## Goal

Explore event search functionality and mobile web navigation.

---

## Areas Tested

- Event search
- Event page
- Navigation
- UI responsiveness

---

## Observations

- Event pages load correctly.
- Navigation between events is smooth.
- Some UI elements behave inconsistently on smaller screens.

---

## Tools Used

USB debugging and Chrome DevTools were used to inspect page behavior and confirm issues.
