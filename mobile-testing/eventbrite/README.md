# Eventbrite – Exploratory Testing

## Project Description

Eventbrite is a platform for discovering and managing events.

Exploratory testing was performed on the mobile web version of the application.

---

## Testing Approach

Exploratory testing focused on the following areas:

- Event search
- Event details page
- Navigation between pages
- UI responsiveness

Testing was performed using mobile debugging tools.

---

## Tools Used

- Android device (Xiaomi Redmi Note 9 pro, Android 10, MIUI version 12.0.3
- USB debugging
- Chrome DevTools

Chrome DevTools was used to inspect network requests and confirm related issues.
