# Mobile Testing Projects

This section contains exploratory and manual testing projects performed on mobile applications.

Testing was conducted using real devices such as iPhone, Android. Android emulator and usb-debugger tool.

Projects included:

- IMDb (Device: iPhone 11 Pro, iOS 26.2.1)
- Eventbrite (Device: Xiaomi Redmi Note 9 Pro, Android 10)
- Evernote (Device: Xiaomi Redmi Note 9 Pro, Android 10)
- Handyman (Emulator: Pixel 8, Android 16)
