# JPetStore – Exploratory Testing

## Project Overview

JPetStore is a demo e-commerce web application used for software testing practice.

This project demonstrates exploratory testing focused on identifying functional and content-related issues in the application.

---

## Testing Focus

Testing was focused on the following areas:

- field validation
- product catalog behavior
- product descriptions
- image display
- general usability of product pages

---

## Testing Approach

Exploratory testing sessions were performed to simulate real user interaction with the application.

The goal was to identify issues affecting:

- correctness of displayed product information
- visual quality of product pages
- validation behavior
- overall user experience
