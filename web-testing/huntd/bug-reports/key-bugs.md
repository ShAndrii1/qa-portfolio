# Key Bugs Identified During Testing

## HTD-24 – User is able to register by filling in the "Email" field with no existing email credentials on the Sign up page

### Description

Users can register without confirming their email address.

### Impact

This allows creation of fake or spam accounts which can reduce trust among recruiters using the platform.

---

## HTD-55 – 404 Error after redirection to the Binance vacancies by clicking on the [1-CLICK APPLY] button

### Description

The main page displays top Web3 companies, however most of the links redirect to outdated or invalid pages.

### Impact

Users may lose trust in the platform if company information is inaccurate.

---

## HTD-30 – Candidate is able to register by filling in the "Desired position" field with invalid data on the "ROLE" stage
## HTD-32 - Candidate is able to register by filling in the "Role" field with invalid data on the "EXPERIENCE" stage

### Description

Users can register as a Candidate with invalid value in the most important fields.

### Impact

Trust and interest from potential serious large recruiters may be lost.
